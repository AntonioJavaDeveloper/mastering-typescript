## 📖 Introdução

Este capítulo apresenta os primeiros conceitos do TypeScript e conduz o leitor à execução de sua primeira aplicação, estabelecendo uma base prática para os estudos que serão desenvolvidos nos capítulos seguintes.

Antes de começar a explorar os recursos da linguagem, é importante compreender o que é TypeScript, qual é sua relação com JavaScript e como o código escrito nessa linguagem chega ao ambiente de execução.

Ao longo deste capítulo, você conhecerá o processo básico de transformação do código TypeScript em JavaScript e executará um exemplo prático para verificar o funcionamento do ambiente de desenvolvimento disponibilizado pelo repositório.

O objetivo não é aprofundar todos os detalhes técnicos neste primeiro contato, mas estabelecer uma compreensão inicial da linguagem e garantir que o ambiente esteja funcionando corretamente.

---

## 🎯 Objetivos do Capítulo

Ao concluir este capítulo, você deverá ser capaz de:

- Compreender o que é TypeScript e sua relação com JavaScript.
- Entender por que o código TypeScript precisa ser transformado em JavaScript para ser executado nos ambientes convencionais.
- Diferenciar, conceitualmente, a transpilação da execução do código.
- Reconhecer o papel do Node.js no ambiente utilizado pelo projeto.
- Executar uma aplicação TypeScript de exemplo.
- Verificar se o ambiente de desenvolvimento está funcionando corretamente.

---

## 🗂️ Organização do Capítulo

O conteúdo está dividido em dois documentos complementares, organizados para apresentar primeiro os conceitos fundamentais e, em seguida, aplicá-los em um exemplo prático.

### 📘 01 - O que é TypeScript?

Neste documento, você conhecerá o TypeScript, sua relação com JavaScript e o processo de transformação do código TypeScript em JavaScript.

Também será apresentada a diferença entre transpilação e execução, além de uma introdução ao papel do ambiente de execução utilizado neste projeto.

### 💻 02 - Primeira Execução de uma Aplicação TypeScript

Neste documento, você utilizará o ambiente de desenvolvimento preparado para o repositório para executar seu primeiro exemplo.

O objetivo é observar o resultado da execução, reconhecer o comportamento esperado e confirmar que as ferramentas necessárias estão funcionando corretamente.
