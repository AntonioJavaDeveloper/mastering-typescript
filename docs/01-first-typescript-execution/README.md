## 📖 Introduction

This chapter introduces the fundamentals of TypeScript and guides you through running your first application, establishing a practical foundation for the topics covered in subsequent chapters.

Before exploring the language's features, it is important to understand what TypeScript is, how it relates to JavaScript, and how TypeScript code reaches the runtime environment.

Throughout this chapter, you will learn the basic process of transforming TypeScript code into JavaScript and run a practical example to verify that the development environment provided by this repository is working correctly.

The goal is not to cover every technical detail at this stage, but rather to build an initial understanding of the language and ensure that the development environment is properly configured.

---

## 🎯 Chapter Objectives

By the end of this chapter, you should be able to:

- Understand what TypeScript is and how it relates to JavaScript.
- Understand why TypeScript code needs to be transformed into JavaScript to run in conventional runtime environments.
- Conceptually distinguish between transpilation and code execution.
- Recognize the role of Node.js in the project's runtime environment.
- Run a sample TypeScript application.
- Verify that the development environment is working correctly.

---

## 🗂️ Chapter Structure

The content is divided into two complementary documents, organized to introduce the fundamental concepts first and then apply them in a practical example.

### 📘 01 - What Is TypeScript?

In this document, you will learn what TypeScript is, how it relates to JavaScript, and how TypeScript code is transformed into JavaScript.

You will also explore the difference between transpilation and execution, along with an introduction to the role of the runtime environment used in this project.

### 💻 02 - First TypeScript Execution

In this document, you will use the development environment configured for this repository to run your first example.

The goal is to observe the execution output, recognize the expected behavior, and confirm that the required tools are working correctly.
